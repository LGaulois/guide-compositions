Questions

Installation et questions fréquentes

Comment installer l'application ?

Téléchargez le fichier sur votre téléphone, ouvrez-le, puis autorisez l'installation d'applications inconnues pour l'application qui l'ouvre (navigateur ou Drive).

Android affiche « Application bloquée » ou un message Play Protect.

L'application ne vient pas du Play Store, donc Play Protect ne la connaît pas encore. Appuyez sur « Plus de détails », puis « Installer quand même ». Sur certains Samsung, désactivez temporairement le « Bloqueur automatique ».

Puis-je utiliser l'application sur plusieurs téléphones ?

Non : le code de licence ne fonctionne que sur un seul téléphone. Pour changer de téléphone, écrivez-nous à legionnairegaulois@gmail.com. En cas de remboursement, le code est désactivé.

Et sur iPhone ?

Pas pour le moment. Seule la version Android est proposée.

Où sont mes données ?

Uniquement sur votre téléphone. L'application ne se connecte à internet que pour vérifier votre code de licence (à l'activation, puis de temps en temps).
